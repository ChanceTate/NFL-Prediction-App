# NFL QB Performance Prediction

A machine learning pipeline that predicts NFL quarterback passing yards from
historical game data, built around honest evaluation: walk-forward validation
by season, ablation-gated feature engineering, and a baseline every model has
to beat.

## Results

Across 7 walk-forward folds (train on past seasons, test on the next):

| Model | Mean MAE (passing yards) |
|---|---|
| LightGBM | ~67 |
| Linear Regression | ~68 |
| Baseline (predict the mean) | ~81 |

The tracked models beat the naive baseline by roughly 17% MAE. Exact numbers
are regenerated by the pipeline on every run (`metrics.json`).

## How it works

1. **Data**: QB game logs and schedules pulled via
   [nflreadpy](https://github.com/nflverse/nflreadpy) (nflverse data).
2. **Features**: rolling form over a QB's recent games (yards, attempts,
   EPA per attempt, trend slopes) plus opponent and game context. Every
   feature must earn its place: see the decision rule below.
3. **Models**: LightGBM and Linear Regression, with a predict-the-mean
   `DummyRegressor` as the sanity floor.
4. **Evaluation**: walk-forward cross-validation by season, so the model is
   always tested on a season it has never seen and no future data leaks into
   training. Metrics are aggregated across folds as mean, standard deviation,
   and worst fold, to distinguish "reliably decent" from "great except when
   it isn't".

## Feature discipline

Features are added through ablation testing, not intuition. A candidate
feature is kept only if it passes either of:

- **Magnitude path**: mean ablation delta >= +0.2 MAE with 5+/7 folds positive
- **Consistency path**: mean ablation delta >= +0.1 MAE with 6+/7 folds positive

[`EXPERIMENTS.md`](EXPERIMENTS.md) logs every feature ever tried, the numbers
it put up, and the verdict, including the many rejections. The pipeline also
reports permutation importance and per-feature ablation deltas on every run.

## Running it

Requires Python 3.12+ and [uv](https://github.com/astral-sh/uv).

```bash
uv sync --all-groups   # install dependencies
uv run python main.py  # run the full pipeline: folds, metrics, feature analysis
uv run pytest          # test suite
uv run ruff check .    # lint
```

The pipeline prints per-fold and aggregate metrics and writes `metrics.json`,
`importance.json`, and `ablation.json`.

## Repository layout

```

src/data.py        data loading (nflreadpy)
src/features.py    feature engineering

EXPERIMENTS.md     the feature experiments log
```

## CI

GitHub Actions runs lint (ruff), format checks, and the test suite on every
push, and compares evaluation metrics against `main` on pull requests.
